# Sonar_Mines_Debris_Detection_And_Segmentation
Detection + segmentation pipeline for mines and debris in forward-looking sonar imagery. YOLOv11 (n/s/m) for detection, SAM-HQ for pseudo-GT mask generation, SAM2 for predicted masks. Evaluated with IoU, Dice, pixel accuracy, precision, and recall across all classes, with full inference/evaluation logs.
